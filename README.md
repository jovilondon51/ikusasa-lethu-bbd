Ikusasa Lethu - BBD Learner Tracking System
A full-stack web application for tracking learners, projects, attendance, and learning content at Ikusasa Lethu Saturday School's BBD Coding Program.

Features
Admin Dashboard: Manage learners, staff, attendance, content, and analytics
Learner Dashboard: Create projects, track progress, earn badges
Project Editor: In-browser code editor with live preview for HTML/CSS/JS
File Uploads: Support for zip extraction and single file uploads
Attendance Tracking: Calendar view with analytics
Docker Support: One-command deployment with docker-compose up --build
Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: PHP 8.2
Database: MySQL 8.0
Editor: Monaco Editor (VS Code's editor)
Containerization: Docker & Docker Compose
Quick Start (Docker)
git clone https://github.com/jovilondon51/ikusasa-lethu-bbd.git
cd ikusasa-lethu-bbd
docker-compose up --build

Then visit:

Website: http://localhost:8080
phpMyAdmin: http://localhost:8081

Default Login

Admin: admin_BBD / IkusasaBBD@2026
